# Sustainability ESG Risk Scores
Obtaining and displaying Sustainalytics ESG risk scores from Yahoo Finance

## Python Tools Used
* **yfinance** -- fetch risk scores from Yahoo! Finance
* **pandas** -- write results into a dataframe
* **altair** -- chart the scores
* **streamlit** -- display the results in a web app

**Web App**: (https://sustainability-esg-data.streamlit.app/)
